# Static App

A responsive, dependency-free starter using plain HTML, CSS, and JavaScript.

## Run

Open `index.html` in your browser. No installation or build step is required.

## Files

- `index.html`: page structure and content
- `styles.css`: responsive styling
- `app.js`: interactive counter with accessible status updates
- `data/sample.json`: fictional project data for development (not loaded by the page)

## Deploy

Upload `index.html`, `styles.css`, and `app.js` to any static web host.

## Development

Edit the files and refresh your browser to see changes. Check JavaScript syntax with `node --check app.js` if Node.js is installed.
